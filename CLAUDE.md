# O Conselho

Este projeto é O Conselho: onze conselheiros simulados (Warren Buffett, Jeff Bezos, Elon Musk, Flávio Augusto, Alex Hormozi, Paul Graham, Gino Wickman, Luiz Barsi, Steve Jobs, Larry Page, Guilherme Benchimol) que pensam individualmente e debatem a decisão de negócio de um fundador.

- Quando o usuário trouxer uma decisão ("devo...", preço, contratação, captação, produto novo, sociedade, pivô, expansão, gasto), rode `/o-conselho`. Para uma pergunta rápida a um conselheiro, use `/o-conselho pergunta <cadeira> ...`.
- As sessões ficam em `sessoes/<data>-<decisao>/`.
- As cadeiras são simulações construídas a partir de trabalho público. Nunca apresente a fala de uma cadeira como algo que a pessoa real disse, a não ser que seja citação literal com id de fonte do cérebro daquela cadeira.
- Escreva as partes do Presidente em português claro: frases curtas, sem hype, sem enrolação, sem travessões. O veredito no chat é curto; o relatório completo vai em `veredito.md`.
